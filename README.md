# Aion2AR Releases

مستودع توزيع إصدارات **Aion2AR** والإعلانات المباشرة.

> الحالة الحالية: **Private — مرحلة اختبار قبل النشر العام**

## ملفات كل Release

يجب أن يحتوي كل إصدار قابل للتحديث التلقائي على الملفين التاليين بالاسم نفسه تمامًا:

- `Aion2AR.exe`
- `Aion2AR.exe.sha256`

ويجب أن يكون Tag الإصدار بالشكل:

- `v0.9.72`
- `v0.9.73`

Aion2AR يقارن رقم الـTag مع رقم الإصدار المبني داخل التطبيق.

## الإعلانات

الملف `Announcements.json` في جذر المستودع يُقرأ مباشرة بواسطة Aion2AR.

تغيير الإعلان لا يحتاج إلى إصدار EXE جديد. استخدم `id` جديدًا لكل إعلان جديد حتى يظهر تلقائيًا للمستخدم مرة واحدة.

## اختبار المستودع الخاص

أثناء مرحلة Private فقط، نسخة التطوير تستطيع القراءة باستخدام متغير البيئة المحلي:

`AION2AR_GITHUB_TOKEN`

لا يتم حفظ الرمز داخل Aion2AR أو داخل هذا المستودع.

بعد نجاح الاختبارات سنحوّل هذا المستودع إلى **Public**، وعندها لن يحتاج المستخدمون إلى أي Token.
