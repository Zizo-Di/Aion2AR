## المميزات

- **تعريب عربي لـ AION 2** — ترجمة مخصصة للاعب العربي مع تحديثات مستمرة بالتزامن مع تحديثات اللعبة
- **دعم أكثر من نسخة** — النسخة العالمية عبر **NC Launcher** و**Steam**، والنسخة التايوانية عبر **NC Launcher**
- **كشف تلقائي لمسار اللعبة** — يبحث البرنامج عن المسارات المعروفة ويمكن اختيار المجلد يدويًا عند الحاجة
- **فحص توافق الإصدار** — يتحقق من إصدار اللعبة قبل التثبيت وينبّه عند وجود اختلاف بين إصدار اللعبة وإصدار التعريب
- **نسخ احتياطي واستعادة** — يحفظ الملفات الأصلية اللازمة قبل التعديل ويعيدها عند إزالة التعريب
- **تثبيت وإزالة بنقرة واحدة** — واجهة عربية واضحة مع سجل لحالة العمليات
- **تحديث تلقائي للبرنامج** — يفحص GitHub بحثًا عن نسخة أحدث ويتحقق من سلامة ملف التحديث قبل استبداله
- **إعلانات وملاحظات إصدار مباشرة** — قسم «آخر المستجدات» يعرض أخبار التعريب والتنبيهات والمناسبات
- **حماية عند تشغيل اللعبة** — يمنع التعديل على الملفات أثناء تشغيل AION 2 لتقليل احتمالية تلف الملفات
- **محمول** — ملف `Aion2AR.exe` واحد، بدون برنامج تثبيت منفصل

## البدء السريع

1. **حمّل** `Aion2AR.exe` من [صفحة أحدث إصدار](https://github.com/Zizo-Di/Aion2AR-Releases/releases/latest)
2. **شغّل البرنامج**
3. اختر **المنطقة**: العالمية أو التايوانية
4. اختر **المنصة** المتاحة: NC Launcher أو Steam
5. تأكد من أن مسار AION 2 تم اكتشافه بشكل صحيح
6. اضغط **«تثبيت التعريب»**
7. وافق على نافذة صلاحيات Windows عند طلبها، ثم شغّل اللعبة

## مهم: توافق إصدار اللعبة

> يعتمد التعريب على إصدار محدد من ملفات AION 2.
>
> إذا صدر تحديث جديد للعبة قبل تحديث التعريب، سيظهر لك Aion2AR تنبيهًا بعدم تطابق الإصدارات. عند وجود تحديث غير متوافق قد يتم إيقاف التثبيت مؤقتًا إلى أن تصدر نسخة تعريب مناسبة.
>
> **لا يُنصح بإجبار التثبيت على إصدار لعبة غير مدعوم.**

## كيف يعمل

يتولى Aion2AR العملية تلقائيًا دون حاجة المستخدم إلى تعديل ملفات اللعبة يدويًا:

| الخطوة | ما يحدث |
|--------|---------|
| 1 | تحديد نسخة AION 2 والمنصة ومسار التثبيت |
| 2 | قراءة إصدار اللعبة ومقارنته بإصدار التعريب المتوافق |
| 3 | التحقق من حالة ملفات التعريب الحالية |
| 4 | إنشاء النسخ الاحتياطية اللازمة للملفات الأصلية |
| 5 | تطبيق ملفات التعريب والتحقق من اكتمال العملية |
| 6 | حفظ حالة التثبيت لتمكين الإزالة والاستعادة لاحقًا |
| 7 | متابعة تحديثات Aion2AR والإعلانات من GitHub |

## إزالة التعريب

إذا أردت العودة إلى ملفات اللعبة الأصلية:

1. افتح Aion2AR
2. اختر نفس المنطقة والمنصة التي ثبت عليها التعريب
3. اضغط **«إزالة التعريب»**
4. انتظر حتى يؤكد البرنامج اكتمال الاستعادة

إذا تم تحديث اللعبة أو إصلاح ملفاتها من المشغل، يستطيع Aion2AR إعادة فحص الحالة الفعلية للملفات بدل الاعتماد على حالة محفوظة فقط.

## المتطلبات

- لعبة **AION 2** مثبتة على الكمبيوتر
- **Windows 10 أو Windows 11 — 64-bit**
- اتصال بالإنترنت لفحص تحديثات البرنامج والإعلانات
- صلاحية Administrator عند تنفيذ عمليات تثبيت أو إزالة التعريب
- لا يحتاج إلى تثبيت .NET بشكل منفصل؛ النسخة المنشورة Self-contained

## حل المشاكل

| المشكلة | الحل المقترح |
|---------|---------------|
| البرنامج لا يكتشف اللعبة | استخدم زر اختيار المجلد وحدد مجلد تثبيت AION 2 الصحيح |
| يظهر تحذير اختلاف إصدار اللعبة | انتظر تحديث التعريب المتوافق وتحقق من «آخر المستجدات» |
| التثبيت أو الإزالة غير متاح أثناء تشغيل اللعبة | أغلق AION 2 بالكامل ثم أعد المحاولة |
| التعريب لا يظهر بعد تحديث اللعبة | افتح Aion2AR وافحص حالة التعريب ثم ثبّت النسخة المتوافقة عند توفرها |
| حدثت مشكلة بعد التثبيت | استخدم «إزالة التعريب» لاستعادة الملفات الأصلية، ثم أعد المحاولة بعد التأكد من توافق الإصدار |

## التحديثات والإعلانات

يستطيع Aion2AR إعلامك عند توفر إصدار جديد من البرنامج، كما يعرض الأخبار والتنبيهات من قسم **«آخر المستجدات»**.

يتم التحقق من سلامة تحديثات البرنامج قبل تطبيقها، وإذا تعذر إكمال التحديث يحتفظ البرنامج بآلية استعادة للنسخة السابقة.
